ENGINEERING STACK

Technology Behind Medilink

A hybrid hardware-software architecture bridging physical NFC wearables with modern, scalable cloud infrastructure.

SIMULATED / HARDWARE COMPATIBLE

NFC (Near Field Communication)

13.56 MHz high-frequency RFID standard (ISO/IEC 14443 Type A). Operates over inductive magnetic coupling within 0–4 cm, eliminating batteries on the wearable tag.

Chipset: NXP NTAG213 / NTAG215 Power: 0 mW (Passive)
IMPLEMENTED IN PROTOTYPE

NDEF (NFC Data Exchange Format)

A standardized binary data payload format defined by the NFC Forum. Encodes a single Well-Known URI Record Type Definition (RTD) pointing directly to the Medilink secure domain.

Payload: URI RTD prefix (0x04) Memory Footprint: < 144 Bytes
SUPPORTED / GITHUB PAGES READY

HTTPS & Transport Encryption

Enforces TLS 1.3 encryption across all client-server communications. Guarantees that URL parameters and profile transmissions cannot be intercepted or modified via man-in-the-middle attacks.

Protocol: TLS 1.3 / HSTS Port: 443 (Encrypted)
IMPLEMENTED & FUNCTIONAL

Web Application (Frontend)

Zero-dependency, high-performance HTML5, CSS3, and Vanilla JavaScript client. Operates natively in mobile Safari, Chrome, and Edge without requiring first responders to install an application.

Stack: Vanilla JS / CSS Grid Load Speed: < 200 ms
FUTURE PRODUCTION ROADMAP

Backend / Microservices API

In production, a Node/Go microservice layer will handle token verification, rate-limiting, responder geostamp authorization, and real-time SMS dispatch to registered emergency contacts.

Architecture: Cloud Run / FastAPI Status: Planned Production Tier
FUTURE PRODUCTION ROADMAP

HIPAA-Compliant Database

Decentralized or encrypted SQL/NoSQL datastore with AES-256 field-level encryption for sensitive EHR records. Distinguishes emergency baseline info from restricted medical history.

Encryption: AES-256 at Rest Status: Planned Production Tier
GOVERNANCE & TRUST

Privacy, Security & Compliance Roadmap

Emergency medicine demands a rigorous balance between instant accessibility for first responders and ironclad patient privacy.

PROTOTYPE NOTICE

Demonstration Environment Notice

This prototype demonstrates the NFC-to-web access workflow using fictional data. It is constructed for hackathon judging and educational purposes. In accordance with clinical informatics principles, Medilink does not claim that this client-side prototype is production-secure without the backend controls detailed below.

01

HTTPS & Strict TLS

Mandatory TLS 1.3 with Certificate Transparency and HSTS prevents spoofing and traffic snooping.

02

Authentication & Authorization

Tiered access: Public emergency view (blood type, allergies) vs. authenticated view for certified paramedics.

03

Granular Access Control

Patients control which data fields are publicly visible versus locked behind an emergency contact PIN.

04

Data Minimization

Only lifesaving vitals are loaded initially. Non-urgent clinical history is omitted to protect patient privacy.

05

End-to-End Encryption

Field-level AES-256 encryption protects personal identifiable information (PII) at rest and during transit.

06

Real-Time Audit Logging

Every profile scan records a timestamp and general IP/region, immediately sending an SMS alert to emergency contacts.

07

Instant Profile Revocation

If a wristband is lost or stolen, the patient can disable the profile ID from their dashboard in one click.

08

Healthcare Regulatory Review

Formal alignment with HIPAA (US), GDPR (EU), and DISHA / Ayushman Bharat Digital Mission standards.

VALUE PROPOSITION

Why Medilink? The Engineering Advantage

Why NFC hardware combined with universal web standards outperforms proprietary apps and engraved medical ID tags.

⚡

Fast, Frictionless Access

Paramedics have zero time to unlock a patient’s phone or search wallets. A 2-second tap delivers critical blood group and allergy alerts during the golden hour.

🔋

Zero Battery Required

Smartwatches and fitness bands die when uncharged. Passive NFC wristbands rely entirely on inductive power from the scanning phone, remaining operational for decades.

📱

No Dedicated App Needed

Proprietary medical apps require responders to download and register before viewing records. Medilink leverages the universal native web browser already installed on every phone.

🔄

Easy to Update Profiles

Engraved metal bracelets become dangerously obsolete when medication doses change. With Medilink, the physical wristband link stays constant while records update in the cloud.

📈

Scalable & Low Unit Cost

Passive silicone NFC wristbands cost between $0.15 to $0.40 at scale, allowing hospitals, universities, and marathon events to distribute them en masse to vulnerable populations.

🏁

Dual QR Fallback Option

In addition to the embedded NFC chip, physical wristbands can feature a laser-etched high-density QR code targeting the exact same HTTPS URL for older phones without NFC.
